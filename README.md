
# Chess Review Prototype

An independent prototype for reviewing completed chess games.

## Current stack

- React
- TypeScript
- Vite
- ESLint
- chess.js
- react-chessboard

## Requirements

Install a supported Node.js LTS release and npm.

## Setup

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```

## Scope

The initial stage establishes the application structure, design
foundation, and development tooling. Chess.com API integration
and Stockfish analysis will be implemented in later stages.

Use documented data sources only. Review third-party terms and
licenses before distributing or commercially launching the app.
