version 3 (GPL-3.0).

Official project:
https://github.com/official-stockfish/Stockfish

Before bundling or distributing the engine:

1. Verify the license for the exact version used.
2. Include the required copyright and license notices.
3. Provide corresponding source code or a GPL-compliant
   means of obtaining it.
4. Apply GPL requirements to any distributed modifications.
5. Review the actual integration and distribution method.

The application must not claim that Stockfish is proprietary
software owned by this project.
