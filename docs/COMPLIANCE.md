
# Compliance Checklist

## Chess.com data

- Use documented public API endpoints only.
- Do not scrape website pages or use undocumented endpoints.
- Respect applicable usage restrictions and rate limits.
- Do not imply affiliation with Chess.com.
- Reassess permissions before public or commercial launch.
- Prefer completed games and post-game analysis only.
- Avoid unnecessary collection or storage of player data.

## Stockfish

- Obtain the engine from an official or verifiable source.
- Review the exact version's GPL license before distribution.
- Include required license notices and corresponding source access.
- Document any engine modifications.

## Website privacy and security

- Do not commit secrets or credentials.
- Do not expose private keys through Vite client variables.
- Use HTTPS for public deployment.
- Collect only data needed for the stated functionality.
- Publish accurate privacy disclosures before collecting personal data.
- Review applicable laws and third-party terms before launch.

## Release status

Prototype only. Compliance checks do not constitute legal advice
or confirmation that every intended use is authorized.
